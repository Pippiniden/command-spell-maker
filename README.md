# 令呪デザイナー (command-spell-maker)

Fateの令呪にインスピレーションを受けた、オリジナルの紋様を組み立てるブラウザツールです。

- パーツ（線・面、全23種）と、先細りの筆で形を置く
- 9点メッシュで形を歪ませる
- 「消しゴム」の形で重なった部分を削る
- 複数の形を選んでひとつに合体する
- 形ごとに一画目〜三画目を割り当て、「一画使う」で消える順番を確認
- PNG / SVG で書き出し（背景: 墨・肌・紙・透明）
- 最初に開くとデフォルト令呪（剣と弧と四芒星の縦長の紋様）が入っています。「デフォルト令呪」ボタンでいつでも呼び戻せます

パーツはすべて汎用の図形で、作品中の令呪そのものは含みません。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。
Google Fonts と [polygon-clipping](https://github.com/mfogel/polygon-clipping) を CDN から読み込むため、インターネット接続が必要です。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | スタイル |
| `app.js` | 図形生成・編集・書き出しのロジック |

編集内容はブラウザの localStorage（キー `reiju-designer-v1`）に自動保存されます。
